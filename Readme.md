# String Converter (Python)

A simple Python project that encodes and decodes messages using a custom algorithm.

## 🔹 Features
- Single-character words remain unchanged.
- Two-character words are reversed.
- Longer words are scrambled:
  - The first letter is moved to the end.
  - Random letters are added at the start and end.
- Decoding restores the original message.
- Interactive menu lets you choose between encoding and decoding.
